# 🌊 BlueDepths - Ocean Life & Marine Conservation Website

## Objective
A responsive, modern web application designed to raise awareness about marine biodiversity, ocean ecosystems, endangered marine species, and crucial conservation initiatives. Built for the Mid-Semester Examination (Web Dev & Cloud Foundation), Problem Statement 10.

## Features
- **Modern Responsive Design**: Fully optimized across all screen sizes with an interactive mobile hamburger menu and sleek glassmorphism aesthetic.
- **Immersive Depth Simulation**: Features a dynamic depth gauge (ranging from 0 to 4,000 meters) paired with smooth background gradients that transition from sunlit waters to the dark ocean abyss as you scroll.
- **Ocean Ecosystems Section**: Detailed breakdowns of vital marine habitats including coral reefs, mangroves and seagrass, and the unexplored deep sea.
- **Filterable Species Catalog**: Interactive IUCN Red List status filters (*Critically Endangered*, *Endangered*, *Vulnerable*) for threatened marine life.
- **Conservation Actions**: Practical, actionable solutions for global marine preservation.
- **Interactive Pledge Form**: Client-side validated form that instantly captures user commitments and dynamically renders submitted pledge details on the page.

## Technologies Used
- **HTML5** (Semantic markup & accessibility labels)
- **CSS3** (Custom properties, CSS Grid, Flexbox, backdrop filters, and responsive queries)
- **JavaScript** (Vanilla DOM manipulation, event listeners, and scroll triggers)
- **GitHub** for source control & **Vercel** for lightning-fast hosting
